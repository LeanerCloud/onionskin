## For `known-issues.md`

The orchestrator lands the ledger entry from this measurement. What it needs:

- **The residual is real and measured**: one file in four has `/P` bit 4 set
  and is opened read-only where Acrobat opens it editable.
- **The opposite asymmetry**: M3 enforces no `/P` bit. It disables editing on
  every encrypted document, which is stricter than any bit, and gates nothing
  else by them - so a document whose `/P` forbids printing can still be printed
  as a raster. Permission enforcement belongs with the write path at M6.
- **The encrypted-and-repaired class is empty here**, which is not the same as
  empty everywhere: the `hayro` sets were not measured.
