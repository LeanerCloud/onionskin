# The three bodies frame-state-compare.txt reports that are not declarations.
#
# The elision rule absorbs the group hop and the whitespace rustfmt moves when
# the longer chain is rewrapped. It does not absorb a brace or a comma rustfmt
# adds when it breaks a line, and it is not meant to: a rule that deleted those
# would be deleting punctuation from a body, which is where a real change hides.
# So the three are read instead. Each is rustfmt reformatting a line the hop
# pushed past 100 columns, and in each the tokens either side are unchanged.
#
# Two of the three are reported because they add punctuation. The first is
# reported only because whitespace beside a delimiter happens not to be
# collapsed, which is a choice and not a consequence: collapsing it could hide
# nothing, since whitespace there is never semantic in Rust, so a rule that did
# collapse it would absorb that hunk and still pass every case. What the
# procedure guarantees is that no punctuation is deleted, which is narrower than
# "no rewrap is absorbed" and is the honest way to read these three.
#
